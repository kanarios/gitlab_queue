# Repository language

All repository-authored content must be written in English, including code comments and docstrings, documentation, configuration prose, UI and other user-facing text, tests, test names, and messages.
Pull request titles and descriptions and all commit messages must always be in English.
Preserve exact external identifiers, quoted external data, and intentional non-English or Unicode test inputs when their original form matters.
This policy does not determine the language of conversations with the user.
