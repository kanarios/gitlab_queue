## Tips

1. **Use browser DevTools** to set viewport to consistent size
2. **Dark mode**: Toggle to showcase both themes
3. **Demo GIF**: Use tools like [LICEcap](https://www.cockos.com/licecap/) or [Kap](https://getkap.co/)
4. **Optimize images**: Use [TinyPNG](https://tinypng.com/) to reduce file size
